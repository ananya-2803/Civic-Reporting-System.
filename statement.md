Civic Reporting System

Problem Statement

Citizens frequently encounter civic problems such as potholes, garbage accumulation, damaged roads, broken streetlights, water leakage, fallen trees, and traffic-related issues. Reporting these problems manually may be inconvenient and the progress of complaints may be difficult to track.

The Civic Reporting System provides a simple computerized solution where users can submit civic complaints, store complaint information, search existing complaints, and track complaint status.

Scope of the Project

The project focuses on developing a basic Python-based civic complaint management system.

The system allows users to:

- Submit civic complaints
- Receive a unique complaint ID
- View complaints
- Search complaints
- Update complaint status
- Generate complaint statistics

The project uses a JSON file for simple data storage.

Target Users

The primary target users are:

1. Citizens who want to report civic problems.
2. Administrators who need to manage and update complaints.

High-Level Features

1. Complaint Registration

Users can enter their name, location, problem type, and description.

2. Complaint Management

Administrators can view complaints and update their status.

3. Complaint Search

Complaints can be searched using complaint ID, location, or problem type.

4. Reporting and Statistics

The system generates a summary containing the total number of complaints and their status and problem-wise distribution.

5. Data Storage

Complaint records are stored in a JSON file.

Expected Outcome

The project provides a simple and organized method for recording and managing civic complaints. It demonstrates the application of Python programming, modular programming, file handling, data processing, validation, and basic reporting.
